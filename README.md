## 🤔 What is JavaScript?

JavaScript (JS) is the programming language of the web. It makes websites **interactive** — buttons that react to clicks, forms that check your input, menus that open and close, and much more. It also runs outside the browser (using **Node.js**) to build servers, apps and tools.

---

## ▶️ How to run the examples

**Option 1 — In your browser (easiest, nothing to install)**
1. Open any website, right click → **Inspect** → **Console** tab.
2. Copy code from a file, paste it in the console, press **Enter**.

**Option 2 — With Node.js**
1. Install Node.js from https://nodejs.org
2. Open a terminal in this folder and run:
   ```bash
   node 01-variables.js
   ```

**Option 3 — Online playground**
Paste the code into https://jsfiddle.net or https://codepen.io

> 💡 `console.log()` prints things on the screen. You will see it in every example.
